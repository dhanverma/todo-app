# React To-Do App

A responsive task management application built with React and Tailwind CSS. This project is part of my journey toward becoming a frontend developer.

## Features

- **Task Management:** Add, complete, and delete tasks.
- **Task Categories:** Organize tasks into Business and Personal categories.
- **Task Filtering:** Filter tasks by All, Active, and Completed.
- **Progress Tracking:** View category-wise task counts and completion progress.
- **Persistent Storage:** Keep tasks saved across browser refreshes using localStorage.
- **Responsive Design:** Adapt the interface to desktop, tablet, and mobile screens.
- **Mobile Navigation:** Access the sidebar through a mobile navigation drawer.
- **Empty States:** Display helpful messages when no tasks match the selected filter.

## Tech Stack

- React
- JavaScript
- Tailwind CSS
- Vite
- Lucide React
- Browser localStorage

## Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Installation

Clone the repository:

```bash
git clone https://github.com/dhanverma/todo-app.git
```

Navigate to the project directory:

```bash
cd todo-app
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.
